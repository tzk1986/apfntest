# sqltest.py 使用说明文档

## 1. 概述

`sqltest.py` 是一个数据库查询与数据导出工具，主要用于连接 `ifood_kitchen` 数据库，查询智能菜谱生成后的排餐计划数据，并将结果导出为 Excel 文件，方便与算法设置进行比对验证。

---

## 2. 环境依赖

- **Python 库**：`pymysql`、`pandas`
- **数据库**：MySQL（`ifood_kitchen`）
- **输出目录**：`d:\tangzk\py\seldom-web-testing\reports\`

---

## 4. SQL 查询说明

文件定义了 3 个基础 SQL 查询，均使用 `PLAN_ID` 参数化：

| 查询变量 | 说明                         | 返回字段                                                       |
| -------- | ---------------------------- | -------------------------------------------------------------- |
| `query1` | 查看每天排餐菜品和重量数据   | 日期、菜名、重量、50克价格、大类、热门菜、制作方式             |

## 5. 功能函数说明

### 5.1 `fetch_data_and_export2()`

**功能**：查询每天排餐菜品的总重量和总价格，计算人均消耗量。

**输出文件**：`reports/output2.xlsx`

**输出列**：
| 列名           | 说明                         |
| -------------- | ---------------------------- |
| 日期           | 排餐日期                     |
| 总重量         | 当天所有菜品总重量           |
| 总价格         | 当天所有菜品总价格           |
| 星期           | 中文星期（星期一至星期日）   |
| 预估人数       | 根据星期映射的预估用餐人数   |
| 人均消耗重量   | 总重量 / 预估人数            |
| 人均消费金额   | 总价格 / 预估人数            |

**预估人数映射**：
| 星期   | 预估人数 |
| ------ | -------- |
| 星期一 | 300      |
| 星期二 | 280      |
| 星期三 | 280      |
| 星期四 | 280      |
| 星期五 | 250      |

---

### 5.2 `fetch_data_and_export3()`

**功能**：在 `fetch_data_and_export2` 基础上增加浮动范围校验、分类占比汇总、热门菜统计和制作方式比例。

**输出文件**：`reports/output3.xlsx`

**输出列**：
| 列名               | 说明                                               |
| ------------------ | -------------------------------------------------- |
| 日期               | 排餐日期                                           |
| 总重量             | 当天所有菜品总重量                                 |
| 总价格             | 当天所有菜品总价格                                 |
| 星期               | 中文星期                                           |
| 预估人数           | 根据星期映射的预估用餐人数                         |
| 人均消耗重量       | 总重量 / 预估人数（保留2位小数）                   |
| 重量浮动范围       | 标准人均重量（350g）±2% 的范围                    |
| 重量浮动值         | 人均消耗重量 - 标准重量                            |
| 重量是否在范围内   | "在范围内" 或 "超出范围"                           |
| 人均消费金额       | 总价格 / 预估人数（保留2位小数）                   |
| 价格浮动范围       | 标准人均价格（24元）±4% 的范围                    |
| 价格浮动值         | 人均消费金额 - 标准价格                            |
| 价格是否在范围内   | "在范围内" 或 "超出范围"                           |
| 分类占比汇总       | 格式：（大荤:小荤:素菜）：XX%:XX%:XX%             |
| 每日热门菜统计     | 格式：大荤（N），小荤（N），素菜（N）              |
| 制作方式比例       | 格式：（炒菜机:蒸烤箱:人工）：N:N:N               |

**标准值配置**：
- 标准人均消耗重量：350g，浮动比例 2%
- 标准人均消费金额：24 元，浮动比例 4%

---

### 5.3 `fetch_all_results_and_export(PLAN_ID)`

**功能**：综合分析函数，将多个查询结果导出到一个 Excel 文件的多个 Sheet。

**输出文件**：`reports/output_all.xlsx`

**Sheet 1：菜品重复率与连续排餐**
| 列名           | 说明                                           |
| -------------- | ---------------------------------------------- |
| 日期           | 排餐日期（YYYY-MM-DD）                        |
| 星期           | 中文星期                                       |
| 菜名           | 菜品名称                                       |
| 重量           | 菜品重量                                       |
| 连续排餐标记   | 1=该菜品连续两天排餐，0=非连续                 |
| 重复比例       | 该菜品在当周重复排餐次数 / 当周总排餐次数     |

**Sheet 2：分类比例与制作方式**
| 列名           | 说明                                               |
| -------------- | -------------------------------------------------- |
| 日期           | 排餐日期                                           |
| 分类占比汇总   | 格式：（大荤:小荤:素菜）：XX%:XX%:XX%             |
| 制作方式比例   | 格式：（炒菜机:蒸烤箱:人工）：N:N:N               |

**Sheet 3：细化分类汇总**
| 列名           | 说明                                               |
| -------------- | -------------------------------------------------- |
| 日期           | 排餐日期                                           |
| 菜品大类       | 大荤 / 小荤 / 素菜                                |
| 细化分类汇总   | 格式：细化分类1(N)，细化分类2(N)                  |

---

### 5.4 `fetch_data_and_export7()`

**功能**：查询每日大类中的热门菜数量（仅统计热门菜标记为"是"的菜品），按日期汇总显示。

**输出文件**：`reports/output7.xlsx`

**输出列**：
| 列名             | 说明                                               |
| ---------------- | -------------------------------------------------- |
| 日期             | 排餐日期（YYYY-MM-DD）                            |
| 每日热门菜统计   | 格式：大荤（N），小荤（N），素菜（N）              |

---

### 5.5 `export_popular_rate_dish_count()`

**功能**：导出 `popular_rate` 不为 0 的菜品在该排餐计划中的排餐次数，按热门度和排餐次数降序排列。

**输出文件**：`reports/popular_rate_dish_count.xlsx`

**输出列**：
| 列名     | 说明             |
| -------- | ---------------- |
| 菜名     | 菜品名称         |
| 热门度   | 菜品热门度数值   |
| 排餐次数 | 在计划中的排餐次数 |

## 7. 使用方法

### 7.1 修改排餐计划 ID

打开 `sqltest.py`，修改第 18 行：

```python
PLAN_ID = 25080403  # 替换为你需要查询的排餐计划 ID
```

### 7.2 选择要执行的函数

编辑文件末尾 `if __name__ == "__main__":` 部分，取消注释需要的函数：

```python
if __name__ == "__main__":
    # fetch_data_and_export2()        # 每天总重量/总价格+人均消耗
    fetch_data_and_export3()          # 综合分析（含浮动校验）
    # fetch_data_and_export7()        # 每日热门菜统计
    fetch_all_results_and_export()    # 完整分析（多Sheet）
    export_popular_rate_dish_count()  # 热门度与排餐次数
```

### 7.3 运行脚本

```bash
python test_dir/sqltest.py
```

运行成功后，Excel 文件将输出到 `reports/` 目录。

## 9. 注意事项

1. 确保数据库 `10.50.11.77:3306` 可访问。
2. 确保 `reports/` 目录存在，否则导出会失败。
3. `PLAN_ID` 修改后所有查询均会生效，请确认 ID 正确。
4. 预估人数仅配置了周一至周五，周末排餐数据可能无法计算人均值。
5. 浮动范围标准值（人均重量 350g、人均价格 24 元）如需调整，请修改 `fetch_data_and_export3()` 函数中的 `standard_weight` 和 `standard_price` 变量。
